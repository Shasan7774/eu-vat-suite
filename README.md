# EU VAT Suite

EU VAT compliance for WooCommerce — correct destination VAT rates, B2B reverse-charge with VIES validation, OSS threshold tracking, and audit-ready reporting.

- **Free core plugin:** correct VAT at checkout for all 27 EU member states, B2B reverse-charge, checkout-safe VIES fallback.
- **Pro:** OSS return dashboard, €10,000 threshold tracker, audit CSV export. Billed securely via Lemon Squeezy.

**Website:** https://shasan7774.github.io/eu-vat-suite/

Built for WooCommerce merchants selling into the EU.
